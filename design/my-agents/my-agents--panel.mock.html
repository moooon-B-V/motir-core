5THE TERMINAL TAB — connecting, live, reconnecting, lost and exited; size, scroll and resize.

One tab today, drawn as a tab. The strip is the shipped tab track (WorkbenchTabs’ shape) holding only Terminal, so the chat story (MOTIR-6863) adds Chat beside it without moving anything; nothing marks the empty place. The strip’s right end carries the connection’s own word and dot — Connecting… / Live / Reconnecting… / Disconnected / Ended.

Reconnecting is the same shell (agent-terminal.md Q5): the tab keeps its session in sessionStorage, a drop or a reload re-attaches it, and the agent replays up to its last 256 KiB so the screen redraws before live output resumes. While reconnecting the screen stays, dimmed, and typing is paused, not lost into a dead socket. After the reconnect window (the panel’s retries give up — about a minute of backing off) it is lost, with Reconnect; the shell is still there unless the agent hibernated meanwhile, in which case Reconnect wakes it and opens a fresh shell (panel 4). Exited (exit, or the shell died) offers Start a new shell.

Size, scroll, resize. The terminal fills the panel below the tab strip, to the bottom of the viewport; the page never scrolls to reach its bottom line. It scrolls inside (a thumb when there is history above), keeps a scrollback of its own, and a reader scrolled up is not yanked down by new output — Jump to latest appears instead. When the window or the panel changes size the terminal refits to whole cells and tells the shell (resize), showing cols × rows for a moment. Monospace, the design system’s code ground and ink, 12px.

6THE REFUSALS — in words, and never another person’s agent.

A refused wake — opening a hibernated agent, or pressing Wake — lands inside the panel, in the terminal area, with the base asset’s panel-5 box and copy unchanged: rose for credits, peach for Motir is busy (a wait, not a fault). The header stays Hibernated; nothing boots and nothing is charged.

Not your agent, or not found. An address naming an agent that is not the reader’s (not_owner 403, relay close 4403) or no longer exists (404) gets one answer that does not say which: no name, no coding agent, no state, no terminal — the server returned none, and the panel must not confirm another person’s agent exists. The list on the left stays the reader’s own with nothing selected; the only way on is back.

The image has no terminal (no_terminal_server, close 4410; agent-terminal.md Q8): the agent is fine and still running, so the header keeps its state and Delete; the terminal area says why and points at the image update (MOTIR-6862) without a date. No button leads anywhere that does not exist yet.

The other refusals the decision names, each with its words: taken_over (another tab attached the same shell), session_limit (all four sessions attached elsewhere), 4502 (the machine did not answer — the reconnect loop runs first, and this is its lost face). Two codes have no words, on purpose: 4401 (a stale ticket) mints a new ticket and retries once, silently; not_running / 4409 is the panel’s cue to wake the agent (panel 4).
