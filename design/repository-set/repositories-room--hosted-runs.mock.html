Repositories — where Motir’s app can write

MOTIR-6518 (third draft) · a DELTA on design/repository-set/repositories-room.mock.html (MOTIR-4674, the room as MOTIR-4954 reshaped it), drawn to docs/decisions/hosted-run-runs-the-cli-as-the-app.md. A hosted run writes as Motir’s GitHub App, never as a person — the person pressing Run hosted needs no GitHub account, so nothing here asks them to link, connect or reconnect one, and Settings → Account → Git is not touched. What remains is a fact about each connected repository: can Motir Integration write there, and if not, who has to do what.

One line per connected repository. The Hosted by Motir row carries none: Motir writes there with its own app (motir-studio), so there is nothing to accept or reconnect. Review permissions on GitHub opens the installation’s own settings page (githubInstallationManageUrl), where GitHub shows the pending permission request. Reconnect hands off to GitHub’s install screen for Motir Integration (githubAppInstallUrl), where the repository is added back to the installation — repository selection happens on GitHub, never in a picker here.

The three states, and why each looks as it does. Ready is a quiet fact. Needs updated permissions and can no longer reach are the warning surface, because each is the one state that refuses a run. The permission line is per installation, so it appears on every row of that GitHub account at once — here acme-labs, while acme-inc has already accepted. Its copy names who can fix it — an owner of that GitHub account — because the admin reading this room often isn’t one, and the person who pressed Run hosted may not be on GitHub at all. A repository that is not connected at all is the shipped room’s own business and draws nothing new.

A run is refused as a whole and explained per repository. A hosted run covers every repository its card touches — several for a multi-repository card, the union of the children’s for a parent — and it is checked before anything is minted or booted. The notice keeps the refused slot’s Not started — prefix, counts the repositories it can’t write, and lists each one with the decision’s reason verbatim and a link to that repository’s row in the Repositories room, not straight to GitHub: the person who pressed Run hosted may not be the GitHub owner who has to act, and the room names who is. A repository Motir created never appears here.
