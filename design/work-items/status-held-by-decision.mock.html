Story MOTIR-4887 · design MOTIR-5523 · gates MOTIR-5528 (item page · quick view · edit page) and MOTIR-5529 (the list row), and is composed by the board design MOTIR-5525. While an awaiting gate owns one of the item's moves (ADR approval-gates.md §6d AMENDMENT, rules 1–5), the status control itself says the status can't be moved there directly, and hands the reader the door: one Review & approve button into the full-screen approval overlay. Only the move a decision or a merge performs is held — which one depends on whether the card has an open pull request (REVISED 2026-09-14, rule 2b). Every value below that names a status or a gate kind is an example of an interpolated value ({status} = In Review → Done, {decision} = design approval / pull-request approval).
