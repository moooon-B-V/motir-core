The Difficulty condition row — list and board filter builder

MOTIR-6097, for MOTIR-6100. Difficulty is a nullable closed enum, so it takes the registry’s nullable-enum operator set — the same four Work type offers: is any of · is none of · is empty · is not empty. It joins the Fields group directly after Work type. The value listbox lists the three values easiest first, each with the same faint signal glyph the item page uses. The same builder is mounted by the board’s filter control, so one row serves both.
