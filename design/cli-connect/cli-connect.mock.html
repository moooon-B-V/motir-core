Panel 0 — the entrance · door 1: the CLI hands the browser a URL · door 2: the app's own path to the connect panel

Door 1 → /device

API tokens

Personal access tokens let your coding agents reach Motir over the MCP server. Each token acts as you — give every agent its own, and revoke any you no longer use.

Connect the CLI

Run Motir from your terminal — motir next, motir run, motir auto.

1 · Install
npm install -g @motir/cli
2 · Sign in
motir login

motir login shows a short code and opens Motir in your browser. Approve it there and the terminal is connected — there is no token to copy by hand.

No browser on that machine? motir login prints the code and the URL to open anywhere, so SSH sessions and containers use the same command. For an unattended agent, set MOTIR_TOKEN instead.
