Setting the planning target — a Search control, a search with its own field, and Set as target on the canvas

A delta of target-picker.mock.html panels 1, 2 and 4, and of the shared canvas's selected-card chrome. Story MOTIR-6894; this card MOTIR-6895. The code cards that build it: MOTIR-6897 (the composer's Search control and popover) and MOTIR-6898 (the canvas action). The number match every panel relies on is MOTIR-6896's, in the shared search.

Two decisions carry the sheet. The search gets its own field, so a space is part of the query instead of the end of it. A pick closes the search and puts the person back in their sentence. Everything else here follows from those two.

Esc is swallowed by the popover, so the planning surface's own Esc does not close the whole surface.

The @ hands off; it does not stay in the text. An @ typed at a word boundary is removed from the draft the moment it is typed, the caret stays where it was, and focus moves to the popover's field. Every key typed after it lands in the search, so @plan approval searches “plan approval” — which the inline query could not, because it ended at the first space. The target goes to the TRAY, never inline into the message (target-picker panel 2's decision, unchanged).

A literal @ at the start of a word is the one thing this costs. It is rare in a planning instruction and the shipped picker already treated it as a trigger; an @ inside a word (an email address) is untouched.

Where every key goes — the composer and the popover share one keyboard

new — settles the hand-off
Key In the message field In the popover's field
@ at a word boundary Opens the popover. The @ is consumed; focus moves to the popover field. An ordinary character of the query.
↑ ↓ Move the caret between lines (unchanged). Move the active row, skipping rows that are already targets; wraps.
Enter Sends the turn (unchanged). Shift+Enter breaks the line. Adds the active row as a target and closes the popover. With no pickable row it does nothing — it never sends the message from here.
Esc Reaches the surface's own Esc (unchanged). Closes the popover and is swallowed. Focus returns to the message field at the caret it left.
Tab Moves focus on (unchanged). Closes the popover, like a click outside; focus moves on from the Search control.
A click outside — Closes the popover. A click on the canvas both closes it and does what the click does there.
IME composing Enter confirms the candidate, never sends (unchanged). Enter confirms the candidate, never picks — the same three-signal guard.

A pick closes the popover. The reference is how the pickers people already use hand a reference back to the text they were writing: GitHub's # issue picker in a comment box, Slack's @ mention and Cursor's @ context picker all close on the pick and put the caret back in the sentence. Most turns anchor at one item, so the common case costs no extra key; a second target is one more @ or one more click on the Search control. Keeping the popover open for several picks (the GitHub Assignees menu model) was rejected: it would leave focus in a search after the person had got what they came for, and the next key they typed for their message would go into the query.

Esc returns focus to the message at its caret — the same place a pick returns it — whether the popover was opened by the control or by @. Opened from the control with the caret never placed, the caret goes to the end of the draft.
