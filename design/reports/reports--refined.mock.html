Flat at 640 px: label width ≈ 78 px + 12 → 90 px clear; bucket pitch 22.4 px → every 5th, 7 labels — under the minimum of 8, so the rule angles them. Angled labels need only 16 px along the axis, so every bucket gets one. The bottom margin grows 46 → 64 px and the plot shrinks by the same 18 px: total height stays 396.

Hover or focus on any bucket — labelled or not — shows its full date and both values (2b). The <details> table below keeps every one of the 90 buckets; thinning is a drawing decision, never a data one.

The rule, as the primitives implement it. (1) bucket pitch = plot width ÷ (n − 1) for lines and difference areas, ÷ n for bars; (2) flat spacing = label width + 12 px; show every ⌈spacing ÷ pitch⌉-th bucket starting at the first; (3) always draw the last bucket’s label, dropping any earlier one closer than the spacing; (4) if fewer than 8 labels remain, set the angle to −45° (text-anchor end, pivot under the tick), recompute with 16 px spacing and grow the bottom margin to 64 px. LineChart, DifferenceAreaChart and BarChart share one helper over ChartFrame’s plot box.

3c · The copy structure on a second report — Workload (the same two-part shape on all eight)
Back to reports
ReportsWorkload

Workload

Motir · open work by person · last 30 days

What it shows. Who is carrying how much open work in a period, ranked by total, in story points or work items.

How to read it. Each bar is one person. The first colour is work assigned to them; the second colour is unassigned work that they reported, so you can see who is likely to be asked to pick it up. The grey bar is unassigned work nobody reported. A very long bar beside short ones is an uneven load; a long second segment is a backlog waiting for an owner.

Part Specification
Placement Between the header (breadcrumb · title · sub-line) and the controls row; the toggle sits at the header’s right edge, level with the title.
Control A ghost small Button: info glyph + label + chevron. Label “Hide help text” when shown, “Show help text” when hidden. aria-expanded true/false and aria-controls the region.
Region A --el-tint-lavender callout (--radius-card, padding 12 × 16), ink --el-text-strong (AA on the tint). Two paragraphs: What it shows (one sentence) and How to read it (axes, colours, what a good or bad shape looks like). When hidden it is removed from the layout, not just visually hidden.
Default and memory Shown on the first visit. Hiding it on any report hides it on every report and on every later visit in this browser (one shared preference, kept in browser storage; no account setting). It is a per-reader convenience: nothing on the server changes.
Not a shallow-URL state It writes no URL parameter, so a copied report link never carries it.

Final en copy for all eight reports belongs to the help-text card; the two samples above fix the structure and approximate length (one sentence + 2–3 sentences).
