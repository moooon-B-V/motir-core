Platform admin console — Fleet settings

MOTIR-8703 · story MOTIR-8699. One new Operations page, /admin/fleet-settings, where a superadmin turns Motir’s private repositories’ CI onto the fleet — only when the nine-condition readiness verdict says ready — and turns it off at any time. Every flip asks for a reason and writes fleet.org_ci.enable / fleet.org_ci.disable to the audit log. Composes console.mock.html’s shell and confirm grammar. Gates the /admin setting UI card.

1 · OFF · ready — a superadmin, inside the shell. The ACCESS PATH is the new Fleet settings row in the rail’s Operations group, directly after Monitoring (icon ServerCog, active here). Every condition is met, so the switch is enabled: moving it to ON opens the confirm (Panel 6). The repositories are EXAMPLES — today’s three private ones on moooon-B-V; the list is read at runtime.
