Job runs · System tab — dead letters with no workspace

A DELTA on delivery-state.mock.html (MOTIR-3514), which is a record and is not edited. A system job (for example system.platform-meter-report) dead-letters with workspace_id NULL. Nothing can replay such a row today: the Dead letter tab's Replay is workspace-scoped and refuses it. This asset draws where a PLATFORM_ADMIN_EMAIL operator sees those rows and replays them, in every state, and every state where the control is absent. Built for MOTIR-8083, which builds to it and re-decides none of it.

Panel 1 · Placement — the System tab gains a section ABOVE its runs

Two sections, each with its own heading, on the one tab. Dead letters come first because they are the only thing on this tab an operator can act on, and a standing one is a chore owed. System runs follow, unchanged. The status filter and the pager move INTO the runs section's header and foot: they filter and page runs, and a run status means nothing for a dead letter (the two-dimensions-in-one-control mix MOTIR-3514's notes refuse). The dead-letter section has neither: it lists every row that has not been replayed, plus rows replayed in the last 7 days, unreplayed first. Refresh stays where it is and refreshes both.
