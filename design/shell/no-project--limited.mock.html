Eikooc is a Limited Member of moooon added to no project (the 0-projects row of the workspace Members delta). Every project-scoped route renders this shell instead of a project page: the top bar keeps the workspace switcher and swaps the project crumb for an italic No project; the top bar’s Create (a work item, into the active project) is NOT rendered, because there is no project to create into; the rail is the shipped rail, and each of its project-scoped rows lands on this same shell. The home area is the shipped EmptyState (a Card, FolderKanban glyph, serif title, --el-text-secondary body) saying who can fix it. Access path: this is the landing — lib/navigation/landing.ts after sign-in, and the target of a workspace switch.
