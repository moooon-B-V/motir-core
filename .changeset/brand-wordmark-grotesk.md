The wordmark is set in Space Grotesk (`--font-grotesk-source`), the face motir.co's type defaults to, instead of Inter, a touch tighter (−0.03em) and larger (0.74 of the lockup size). It stays pinned to the face, so a user's Appearance type pairing never re-letters it, and it falls back to Inter where Space Grotesk is not loaded.
